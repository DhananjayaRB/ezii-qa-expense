🚀 Getting Started

System Overview

This comprehensive expense management system streamlines your entire expense workflow from submission to payment. The system supports multiple user roles and provides advanced features like AI-powered receipt processing, approval workflows, and real-time analytics.

User Roles

  • 👤Employee: Submit expense claims, requests, and upload receipts
  • 👨‍💼Manager: Review and approve employee expenses
  • 💼Accountant: Process payments and manage financial workflows
  • ⚙️Admin: Configure system settings and user management

First Login Steps

  1. Access the system through your organization's login portal
  2. Complete your profile information if prompted
  3. Familiarize yourself with the dashboard layout
  4. Take the interactive product tour for your role
  5. Configure notification preferences

👤 Employee Features

💰 Expense Claims

Submit and track reimbursement requests for business expenses.

Creating an Expense Claim

  1. Navigate to Employee → Claim in the sidebar
  2. Click "New Claim" button
  3. Fill in basic information:
    • Expense date
    • Category (Travel, Meals, Office Supplies, etc.)
    • Amount and currency
    • Description of the expense
  4. Upload supporting receipts (drag & drop or browse)
  5. Add line items if multiple expenses in one claim
  6. Set cost distribution if applicable
  7. Review all information and submit
💡 Pro Tip: Use the AI receipt scanner to automatically extract expense details from your receipts. This saves time and reduces errors.

Tracking Claim Status

  • 📝Draft: Claim saved but not submitted
  • ⏳Submitted: Awaiting manager review
  • 👀Under Review: Being reviewed by approver
  • ❓Queried: Additional information requested
  • ✅Approved: Ready for payment processing
  • 💰Paid: Reimbursement completed
  • ❌Rejected: Claim denied with reasons

📝 Expense Requests (Pre-Approval)

Request approval for future expenses before incurring them.

Creating an Expense Request

  1. Navigate to Employee → Request
  2. Click "New Request" button
  3. Select request type:
    • Travel Request
    • Training Request
    • Equipment Purchase
    • General Business Expense
  4. Provide detailed justification
  5. Estimate total cost
  6. Set expected date range
  7. Submit for approval
💡 Best Practice: Always get pre-approval for expenses over your delegated authority limit to avoid claim rejections.

📄 Receipt Uploads & OCR Processing

Upload receipts and leverage AI to automatically extract expense data.

Using AI Receipt Processing

  1. Navigate to Employee → Uploads
  2. Upload receipt files (JPG, PNG, PDF up to 5MB)
  3. AI automatically extracts:
    • Vendor name and details
    • Transaction date
    • Total amount
    • Tax amounts
    • Line items (when possible)
    • Suggested expense category
  4. Review and correct extracted information
  5. Create expense claim directly from processed data
  6. File receipts for future reference

Supported File Formats

  • JPEG/JPG images
  • PNG images
  • PDF documents
  • Maximum file size: 5MB per file

Manager/Approver Dashboard

Efficiently review and process employee expense submissions.

Reviewing Expense Claims

  6. Process bulk approvals for similar items

🔧 Troubleshooting

Common Issues & Solutions

Login Issues

  • Clear browser cache and cookies
  • Try incognito/private browsing mode
  • Check with IT admin for account status
  • Verify internet connection

File Upload Problems

  • Check file size (max 5MB)
  • Verify file format (JPG, PNG, PDF)
  • Ensure stable internet connection
  • Try refreshing the page

OCR Processing Issues

  • Ensure receipt image is clear and well-lit
  • Avoid blurry or distorted images
  • Check if text is readable
  • Try different image orientations

Performance Issues

  • Close unnecessary browser tabs
  • Update to latest browser version
  • Check internet bandwidth
  • Contact support for server-side issues
⚠️ Important: If you encounter persistent issues, contact your system administrator or support team with specific error messages and steps to reproduce the problem.
